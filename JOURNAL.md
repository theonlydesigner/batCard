# 2026-09-06: september 6: schematic capture, easyeda footprints & batman silkscreen

**Total time spent: 2.5 hours**

Started working on the actual PCB today. First, I mapped out everything I’d need for the build and spent a chunk of time hunting down all the component footprints on EasyEDA. Once I had those locked down, I captured the full schematic. Next up, I imported all the components into the PCB editor and started laying everything out (basically playing digital Tetris trying to keep the layout clean). Added some custom silkscreen text to display my info on the board, plus a Bat-signal logo because obviously Batman is elite and the empty PCB space was begging for it. With the layout finished, now I just need the funding grant to come through so I can actually order the board!
